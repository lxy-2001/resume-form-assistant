# Feature SDD 规格目录

本目录只存放按 Feature 组织的 Spec-Driven Development（SDD）产物。

每个 Feature 使用一个独立目录，例如：

```text
specs/001-profile-library/
├─ spec.md
├─ plan.md
├─ tasks.md
└─ checklists/
```

项目级产品文档放在 `docs/product/`，架构说明放在 `docs/architecture/`，头脑风暴记录放在 `docs/discussions/`。`.specify/memory/constitution.md` 保存项目 Constitution；`.agents/skills/` 保存 Spec Kit 的执行技能，不存放 Feature 规格。
